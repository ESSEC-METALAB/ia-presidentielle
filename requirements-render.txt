# What building the site needs, and nothing else.
#
# Vercel builds the preview for every pull request — that is the whole reason
# it was chosen over Pages, because the directeur de la publication reviews the
# rendered site rather than a diff. Installing the full requirements.txt there
# would drag in pymupdf, trafilatura and both model SDKs to render static HTML:
# slower, more to go wrong, and none of it reachable from render.py.
#
# Versions are pinned identically to requirements.txt, and
# tests/test_render.py::test_the_render_dependencies_match_the_full_set
# fails if they drift — a preview built against different versions from
# production is a preview of something else.

PyYAML==6.0.3
feedgen==1.0.0
